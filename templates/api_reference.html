先建立整体认识

  1. 选择数据源和问题：Google Search 面向网页；Maps 面向地点；URL Context 读取指定 URL；Agent Search 与 RAG Engine 使用你的数据；其他模式连接各自的搜索后端。
  2. 请求：GenerateContentConfig.tools 选择工具，ToolConfig.retrieval_config 提供可选语言/坐标；RAG 检索选项在 VertexRagStore.rag_retrieval_config 中。留空表示 Demo 不显式设置，服务默认行为可能不同。
  3. 响应：candidates[].content 是生成内容；grounding_metadata 描述来源和引用；URL Context 使用独立的 url_context_metadata；usage_metadata 是用量。

grounding_chunks 是来源块；grounding_supports 将答案中的片段关联到来源索引；segment.start_index/end_index 是 UTF-8 字节偏移。检索词与辅助字段因工具、模型和响应而异。字段为空不能单独证明未检索，引用也不保证内容正确。

当前 UI 已接入模型、问题、重试、坐标、检索语言、temperature、max output tokens，以及各模式连接项；Search 排除域名；Maps widget；Agent Search 的 filter/max_results；RAG 的 top_k、文件 ID、距离或相似度阈值、元数据过滤、Weaviate hybrid alpha 和重排配置。其它表中字段为 SDK 参考，未必由本 Demo 透传。

查看源数据：普通发送的结果区提供“SDK 返回的 groundingMetadata 全字段”；它是 SDK 解析后的非空字段，不是 HTTP 原始报文。二进制以 Base64 展示。流式模式显示最后一个包含 metadata 的事件，部分结果可能分批到达。

最小 Python 示例：先搜索，再查看来源

需安装 google-genai、配置项目与身份；模型 ID 需替换为项目可用且支持工具的模型。

from google import genai
from google.genai import types

client = genai.Client(vertexai=True, project="PROJECT_ID", location="global")
response = client.models.generate_content(
    model="MODEL_ID",
    contents="请解释什么是 grounding，并列出来源。",
    config=types.GenerateContentConfig(
        tools=[types.Tool(google_search=types.GoogleSearch())]
    ),
)
print(response.text)  # 生成回答
for candidate in response.candidates or []:
    gm = candidate.grounding_metadata
    if gm:
        print(gm.grounding_chunks)    # 来源块
        print(gm.grounding_supports)  # 回答片段与来源的对应关系

替换工具即可改变数据源：Maps 使用 types.Tool(google_maps=types.GoogleMaps())；URL Context 使用 types.Tool(url_context=types.UrlContext()) 并在问题中提供公开 URL。模式、模型兼容性和返回字段需以官方文档为准。

RAG 请求示例：检索参数逐次设置

先创建 corpus 并导入文件。top_k 是数量上限，距离阈值只保留距离小于指定值的片段；0.5 仅作示例，不能视为正确率或通用推荐。

rag_tool = types.Tool(
    retrieval=types.Retrieval(
        vertex_rag_store=types.VertexRagStore(
            rag_resources=[types.VertexRagStoreRagResource(
                rag_corpus="projects/PROJECT/locations/REGION/ragCorpora/CORPUS"
            )],
            rag_retrieval_config=types.RagRetrievalConfig(
                top_k=10,  # 最多返回的候选片段数
                filter=types.RagRetrievalConfigFilter(
                    vector_distance_threshold=0.5  # 示例；按数据评测调参
                ),
            ),
        )
    )
)
response = client.models.generate_content(
    model="MODEL_ID", contents="问题", 
    config=types.GenerateContentConfig(tools=[rag_tool]),
)

要排查检索与生成各自的问题，可先单独调用 retrieveContexts 检查片段和分数，再比较生成响应；单独检索成功不能证明另一次生成请求一定用了相同片段。
