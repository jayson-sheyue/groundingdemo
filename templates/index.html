Search（网页）· 文字问答

模型搜公开网页 → 生成文字回答 → 返回 groundingSupports 高亮 + web.uri 来源。 适合事实、新闻、规格核对。

产出 = 文字 + 网页引用

Image Search · 生图接地

需 gemini-3.1-flash-image + responseModalities: IMAGE。 模型先通过图片搜索找真实视觉参考，再生成图片。 价值：地标/产品外观更准，不靠纯训练记忆「猜」。

产出 = 生成图 + 可选参考来源

Maps · 地点数据

启用 googleMaps，数据源是 Google Maps 地点生态，不是网页 SERP。 lat/lng 是位置上下文，不等于 Maps 工具本身。

工具 = googleMaps

URL Context · 指定页面

把公开网页或 PDF URL 直接放进问题。模型读取指定内容，可单独用，也可与 Google Search 联用补足最新信息。

官方 URL Context 文档 ↗

Agent Search · Vertex 自有数据

将 Gemini 接到 Vertex AI Search / Agent Search 的网站或企业文档数据源；可与 Google Search 组合扩展，但本 demo 单独展示可核验的私域 RAG。

官方 Agent Search 文档 ↗

RAG Engine · 受管语料库

为需要切块、向量检索、评估与数据生命周期控制的企业知识库提供可配置的托管 RAG。

适合复杂知识库 ↗

自定义 Search API · 复用现有检索

连接符合 SIMPLE_SEARCH 协议的内部搜索服务，无需迁移 CRM、工单或行业数据。

适合既有搜索投资 ↗

Elasticsearch · 既有 Elastic 索引

直接为 Elastic 索引加上带引用的生成式问答，适用于文档、日志和商品检索摘要。

适合 Elastic 用户 ↗

Parallel / Exa Web · 伙伴 Web 索引

面向多跳研究与高时效 Web 任务的 LLM 优化检索，适合尽调、KYC 与深度研究。

适合深度研究 ↗

Enterprise Web · 合规 Web 索引

在更受控的 Web 索引上获取时效信息，服务金融、医疗与公共部门等受监管场景。

适合合规研究 ↗

能力、业务价值与适用场景

选择原则：先按“事实来自哪里”选数据源，再按合规、时效和企业已有基础设施决定实现方式。所有模式均应向最终用户展示返回的引用与来源。

Google Search
公开实时 Web		用可核验的实时信息降低新闻、政策、价格与产品事实的过期风险。研究助手、客户支持、竞品/市场动态、旅行与购物决策。需展示 Search Suggestions 与引用。官方文档 ↗

真实视觉参考		让生成图参考现实世界外观，降低地标、建筑、商品视觉“想当然”。营销创意、目的地预览、商品概念图、活动视觉素材。Gemini 3.1 Flash Image 预览能力；必须提供归因。官方文档 ↗

    网页 Search 模式

    适合「什么时候 / 多少钱 / 谁赢了」等文字事实题。 结果区展示：引用高亮、webSearchQueries、可点 web.uri。 模型推荐 gemini-2.5-flash。

    Image Search 生图接地 · 与网页 Search 完全不同

    不是「列出图片来源」的文字问答，而是：先搜真实参考图 → 再生成一张新图。 必须选用 gemini-3.1-flash-image，并开启 responseModalities: TEXT + IMAGE。

    1. 你描述画面要生成什么场景/主体
    2. imageSearch检索 Google 图片作视觉参考
    3. 模型生图inline 图片写入响应
    4. 可选元数据imageSearchQueries / 参考来源块

    使用前检查

    打开官方前置条件 ↗

    排除域名 exclude_domains（仅 Google Search · Vertex）

    写入 GoogleSearch(exclude_domains=[...])，检索时不使用这些域名做 grounding。 Enterprise Agent Platform 的 Google Search 配置；其余九种模式不使用此项。 可填域名或粘贴 URL（会自动取主机名）。上限约 2000 个。

    Agent Search / Vertex AI Search data store（仅 Agent Search 模式）

    填完整资源名，例如 projects/PROJECT/locations/global/collections/default_collection/dataStores/DATASTORE。此路径使用现有 Vertex 凭证。

    企业 Grounding 连接配置
