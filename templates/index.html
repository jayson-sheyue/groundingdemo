Grounding Demo

面向 Gemini 2.5+：网页 Search（文字问答 + 引用）、 Image Search 生图接地（搜真实参考图再生成）、Maps、流式与 GCS 多模态。 说明见 learning_guide.md。

Search（网页）· 文字问答

模型搜公开网页 → 生成文字回答 → 返回 groundingSupports 高亮 + web.uri 来源。 适合事实、新闻、规格核对。

产出 = 文字 + 网页引用

Image Search · 生图接地

需 gemini-3.1-flash-image + responseModalities: IMAGE。 模型先通过图片搜索找真实视觉参考，再生成图片。 价值：地标/产品外观更准，不靠纯训练记忆「猜」。

产出 = 生成图 + 可选参考来源

Maps · 地点数据

启用 googleMaps，数据源是 Google Maps 地点生态，不是网页 SERP。 lat/lng 是位置上下文，不等于 Maps 工具本身。

工具 = googleMaps
附件在点击「发送 / 流式 / 预估 Token」时自动上传至 GCS，与文字同一轮请求；可与 Search/Maps grounding 同时使用。

    网页 Search 模式

    适合「什么时候 / 多少钱 / 谁赢了」等文字事实题。 结果区展示：引用高亮、webSearchQueries、可点 web.uri。 模型推荐 gemini-2.5-flash。

    Image Search 生图接地 · 与网页 Search 完全不同

    不是「列出图片来源」的文字问答，而是：先搜真实参考图 → 再生成一张新图。 必须选用 gemini-3.1-flash-image，并开启 responseModalities: TEXT + IMAGE。

    1. 你描述画面要生成什么场景/主体
    2. imageSearch检索 Google 图片作视觉参考
    3. 模型生图inline 图片写入响应
    4. 可选元数据imageSearchQueries / 参考来源块

    混合检索 · 仍是文字问答

    同时开 web + image 检索，回答仍是文字（可含网页与图片块来源）。 不是生图模式；要体验 Image Search 价值请选「生图接地」。

    网页 Search → web.uri；Image Search 生图 → 输出 inline_data 图片 + 可选 image.source_uri。 官方文档 · Image Search

    排除域名 exclude_domains（网页 Search / 混合模式 · Vertex）

    写入 GoogleSearch(exclude_domains=[...])，检索时不使用这些域名做 grounding。 Vertex AI 支持；Gemini Developer API（API Key）官方标注不支持。 Maps 模式下此框无效。可填域名或粘贴 URL（会自动取主机名）。上限约 2000 个。

    位置上下文 latLng（可选，两种模式都能用）

    留空 = 不传坐标。Maps 问「附近」时强烈建议传；Search 问天气/本地政策时也可传。 这与切换「Maps grounding」是两件不同的事。
